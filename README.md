# My Dotfiles 

This is an ongoing repo for my dotfiles for Arch Linux. Below is a setup guide, planned future features and improvements, as well as a list of applications and dependencies.

## Setup
- From a new Arch Linux install copy this command into the terminal:
```
sudo pacman -S git
```
- After account setup with git, copy this command into the terminal: 
(NOTE: IT IS IMPORTANT TO CLONE THIS REPOSITORY INTO YOUR HOME FOLDER)
```
git clone https://github.com/BubblyNae/dotfiles.git
```
- Once the repo is installed, navigate to the `InstallScripts` file and launch the `master-installation.sh` script:
```
dotfiles/InstallScripts/master-installation.sh
```
